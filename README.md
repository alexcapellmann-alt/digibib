# DigiBib · Stöbern

Klickbarer Konzept-Prototyp für eine neue Startseite einer digitalen Bibliothek: Stöbern statt Kacheln, „Was gibt es hier überhaupt?“.

- **Ebene 0 – Landschaft:** alle 212.502 Objekte auf einer Zeitachse, umschaltbar zwischen zehn Ordnungen (Themen, Gattungen, Lebensstationen, Epochen, Herkunft, Urheber\*innen, Berufe, Erschließung, interne Ordnung, bisherige Kacheln).
- **Ebene 1 – Auswahl:** eine Zeile, ein Schwerpunkt mit eigener Darstellungsform oder eine Person.
- **Ebene 2 – Gruppe:** Jahrzehnt, Briefwechsel, Gattung, Tag oder redaktionelle Gruppe.
- **Ebene 3 – Objekt:** Digitalisat über IIIF, Querverbindungen über Personen (GND) und Tagesdatum.

Daten: Metadaten der Sammlung über OAI-PMH, Bilder live über IIIF, Personenangaben und Porträts über die GND (lobid.org) und Wikimedia Commons.

Die Seite läuft ohne Server: `index.html` im Browser öffnen.
